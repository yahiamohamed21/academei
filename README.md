# أكاديميا - Academei 🎓

منصة إلكترونية متكاملة لإدارة المراكز التعليمية (السناتر) وتسهيل التواصل بين الإدارة والمدرسين والطلاب. تم بناء واجهة المستخدم بأحدث التقنيات لتقديم تجربة "Premium" عصرية، سريعة، ومتجاوبة.

---

## 📌 ما تم إنجازه (المهام المكتملة)

### 1. صفحات الهبوط والاشتراك (Public Pages)
- **[Feature]** **الصفحة الرئيسية (`/`):** تصميم جذاب وعصري (Landing Page) يعرض مميزات المنصة ويجذب أصحاب السناتر.
- **[Feature]** **شاشة التحميل (Splash Screen):** شاشة تحميل احترافية تظهر عند أول زيارة للموقع.
- **[Feature]** **صفحة الاشتراك (`/subscribe`):** نظام اشتراك متكامل (شاشة منقسمة) يتضمن إدخال البيانات، اختيار المواد، حساب التكلفة (بالجنيه المصري)، واختيار طريقة الدفع، بالإضافة إلى نوافذ تأكيد الدفع والنجاح (Modals).
- **[Feature]** **الصفحات القانونية:** إنشاء صفحات "سياسة الخصوصية" (`/privacy`) و "الشروط والأحكام" (`/terms`) بتصميم احترافي.
- **[Fix]** إصلاح الروابط غير المفعلة في صفحة الاشتراك (شروط الاستخدام وسياسة الخصوصية) لتوجه المستخدم للصفحات الصحيحة.

### 2. نظام تسجيل الدخول والحسابات (Auth Flow)
- **[Feature]** تم تجميع جميع مسارات الحسابات تحت المجلد المنظم `(auth)`.
- **[Feature]** **تسجيل الدخول (`/login`):** واجهة تسجيل دخول للمستخدمين.
- **[Fix]** إصلاح رابط "إنشاء حساب" في صفحة تسجيل الدخول ليوجه المستخدم إلى مسار الاشتراك الصحيح (`/subscribe`).
- **[Feature]** **استعادة كلمة المرور (`/forgot-password`):** واجهة مخصصة لطلب الاستعادة باستخدام **رقم الهاتف**.
- **[Feature]** **رمز التحقق (`/verify-code`):** واجهة إدخال الـ OTP المكون من 4 أرقام مع عداد زمني وتصميم مطابق لحالات الخطأ.
- **[Fix]** حل تعارض مسارات المصادقة وحذف المجلدات المكررة لصفحة `verify-code` من خارج مجلد الـ Auth.
- **[Fix]** إزالة الخلفية الزرقاء المتداخلة في صفحات المصادقة لتتطابق تماماً مع صورة الخريجين الخاصة بالـ Layout الموحد.

### 3. لوحة التحكم (Dashboard)
- **[Feature]** **الهيكل الأساسي:** شريط جانبي (Sidebar) وشريط علوي (Header) لسهولة التنقل.
- **[Feature]** **إدارة الطلاب:** جداول لعرض الطلاب، ونوافذ (Modals) لإضافة وتعديل بيانات الطلاب.
- **[Feature]** **المجموعات والمواعيد:** واجهات لإدارة مواعيد السنتر.
- **[Feature]** **المالية والتقارير:** شاشات لعرض الإحصائيات المالية وتحويل العملة للافتراضي (بالجنيه المصري ج.م).
- **[Feature]** **فريق العمل:** واجهة لإدارة الموظفين والمدرسين داخل السنتر.

### 4. تجربة المستخدم (UI/UX)
- **[Feature]** دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
- **[Feature]** تصميم متجاوب (Responsive) يعمل بامتياز على الجوالات والشاشات الكبيرة.
- **[Feature]** استخدام مكونات متطورة (Tailwind CSS, Lucide Icons, Glassmorphism).

---

## ⏳ ما تبقى لإكمال المشروع (الخطوات القادمة)

### 1. ربط قاعدة البيانات (Backend & Database)
- **[Feature]** اختيار وإعداد قاعدة البيانات (مثل Supabase أو PostgreSQL أو Firebase).
- **[Feature]** بناء هيكل الجداول (Schemas): جدول للمستخدمين، السناتر، الطلاب، المجموعات، الفواتير، وغيرها.

### 2. تفعيل المصادقة الحقيقية (Real Authentication)
- **[Feature]** تفعيل عملية تسجيل الدخول وإنشاء الحسابات بشكل فعلي (بدلاً من الواجهات الثابتة).
- **[Feature]** ربط خدمة إرسال رسائل SMS حقيقية لإرسال كود الـ OTP لرقم هاتف المستخدم.
- **[Feature]** حماية مسارات لوحة التحكم (Protected Routes) باستخدام Middleware لمنع الدخول بدون تسجيل.

### 3. ربط واجهات لوحة التحكم بالبيانات الحقيقية (API Integration)
- **[Feature]** استبدال البيانات الوهمية (Dummy Data) الموجودة حالياً في لوحة التحكم ببيانات حقيقية قادمة من قاعدة البيانات.
- **[Feature]** تفعيل أزرار (إضافة طالب، تعديل، حذف) لتقوم بتحديث قاعدة البيانات فعلياً (CRUD Operations).
- **[Feature]** ربط نموذج "طلب الاشتراك" (`/subscribe`) لحفظ بيانات المشتركين الجدد في لوحة تحكم الإدارة العليا.

### 4. اللمسات النهائية للإنتاج (Production Readiness)
- **[Feature]** إضافة نظام إشعارات (Toast Notifications) للنجاح أو الفشل عند حفظ البيانات.
- **[Fix]** المراجعة النهائية للأخطاء وإجراء اختبارات للمنصة (Testing & Bug Fixing).
- **[Feature]** تحسين الـ SEO الخاص بالموقع لتصدر محركات البحث.
- **[Feature]** الرفع النهائي للمشروع (Deployment) على منصات مثل Vercel ليكون متاحاً للجمهور.
