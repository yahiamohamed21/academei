# أكاديميا - Academei 🎓

منصة إلكترونية متكاملة لإدارة المراكز التعليمية (السناتر) وتسهيل التواصل بين الإدارة والمدرسين والطلاب. تم بناء واجهة المستخدم بأحدث التقنيات لتقديم تجربة "Premium" عصرية، سريعة، ومتجاوبة.

---

##   ما تم إنجازه (المهام المكتملة)

### 1. صفحات الهبوط والاشتراك (Public Pages)
- **الصفحة الرئيسية (`/`):** تصميم جذاب وعصري (Landing Page) يعرض مميزات المنصة ويجذب أصحاب السناتر.
- **شاشة التحميل (Splash Screen):** شاشة تحميل احترافية تظهر عند أول زيارة للموقع.
- **صفحة الاشتراك (`/subscribe`):** نظام اشتراك متكامل (شاشة منقسمة) يتضمن إدخال البيانات، اختيار المواد، حساب التكلفة (بالجنيه المصري)، واختيار طريقة الدفع، بالإضافة إلى نوافذ تأكيد الدفع والنجاح (Modals).
- **الصفحات القانونية:** إنشاء صفحات "سياسة الخصوصية" (`/privacy`) و "الشروط والأحكام" (`/terms`) بتصميم احترافي.

### 2. نظام تسجيل الدخول والحسابات (Auth Flow)
- تم تجميع جميع مسارات الحسابات تحت المجلد المنظم `(auth)`.
- **تسجيل الدخول (`/login`):** واجهة تسجيل دخول للمستخدمين.
- **استعادة كلمة المرور (`/forgot-password`):** واجهة مخصصة لطلب الاستعادة باستخدام **رقم الهاتف**.
- **رمز التحقق (`/verify-code`):** واجهة إدخال الـ OTP المكون من 4 أرقام مع عداد زمني وتصميم مطابق لحالات الخطأ.
- **التصميم الموحد:** استخدام واجهة منقسمة (Split Screen) مع خلفية الخريجين الجذابة لجميع صفحات الـ Auth.

### 3. لوحة التحكم (Dashboard)
- **الهيكل الأساسي:** شريط جانبي (Sidebar) وشريط علوي (Header) لسهولة التنقل.
- **إدارة الطلاب:** جداول لعرض الطلاب، ونوافذ (Modals) لإضافة وتعديل بيانات الطلاب.
- **المجموعات والمواعيد:** واجهات لإدارة مواعيد السنتر.
- **المالية والتقارير:** شاشات لعرض الإحصائيات المالية (بالعملة المحلية ج.م).
- **فريق العمل:** واجهة لإدارة الموظفين والمدرسين داخل السنتر.

### 4. تجربة المستخدم (UI/UX)
- دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
- تصميم متجاوب (Responsive) يعمل بامتياز على الجوالات والشاشات الكبيرة.
- استخدام مكونات متطورة (Tailwind CSS, Lucide Icons, Glassmorphism).

## ⏳ ما تبقى لإكمال المشروع (الخطوات القادمة)

### 1. ربط قاعدة البيانات (Backend & Database)
- اختيار وإعداد قاعدة البيانات (مثل Supabase أو PostgreSQL أو Firebase).
- بناء هيكل الجداول (Schemas): جدول للمستخدمين، السناتر، الطلاب، المجموعات، الفواتير، وغيرها.

### 2. تفعيل المصادقة الحقيقية (Real Authentication)
- تفعيل عملية تسجيل الدخول وإنشاء الحسابات بشكل فعلي (بدلاً من الواجهات الثابتة).
- ربط خدمة إرسال رسائل SMS حقيقية لإرسال كود الـ OTP لرقم هاتف المستخدم.
- حماية مسارات لوحة التحكم (Protected Routes) باستخدام Middleware لمنع الدخول بدون تسجيل.

### 3. ربط واجهات لوحة التحكم بالبيانات الحقيقية (API Integration)
- استبدال البيانات الوهمية (Dummy Data) الموجودة حالياً في لوحة التحكم ببيانات حقيقية قادمة من قاعدة البيانات.
- تفعيل أزرار (إضافة طالب، تعديل، حذف) لتقوم بتحديث قاعدة البيانات فعلياً (CRUD Operations).
- ربط نموذج "طلب الاشتراك" (`/subscribe`) لحفظ بيانات المشتركين الجدد في لوحة تحكم الإدارة العليا.

### 4. اللمسات النهائية للإنتاج (Production Readiness)
- إضافة نظام إشعارات (Toast Notifications) للنجاح أو الفشل عند حفظ البيانات.
- تحسين الـ SEO الخاص بالموقع لتصدر محركات البحث.
- الرفع النهائي للمشروع (Deployment) على منصات مثل Vercel ليكون متاحاً للجمهور.
